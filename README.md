# Patient-Level-Evaluation-of-a-Hybrid-CNN-Texture-Network-for-Childhood-Medulloblastoma-Subtyping
Image-level cross-validation inflated subtype accuracy to 98–100%; under leave-one-patient-out validation, DSAF-Net subtype classification was indistinguishable from a majority baseline (60% vs 50%, p=0.248). Only normal-vs-abnormal detection generalized (balanced accuracy 96.5–98.0%).
